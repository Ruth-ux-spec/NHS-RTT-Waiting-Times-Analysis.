Explanation¶

  1. Loaded the data (pd.read_csv with the full path) The first error was a path problem, not a file problem. Jupyter looks in its own working folder, and the file was in Downloads. Giving the full path fixed it.

  2. Inspected the schema (df.shape, df.dtypes, df.info(), df.head()) This tells you what you're working with: 178,171 rows and 121 columns. 107 are decimals (the week counts), 13 are text (names and codes), and 1 is an integer. At this stage, you're asking: what does one row represent, and which columns matter?

  3. Checked data quality (df.duplicated().sum(), df.isnull().sum())

    • Duplicates: 0, so no rows needed removing. • Nulls: about 56k in the long-wait columns. In this dataset a blank means no patients waiting at that week band, not missing information.

  4. Looked for summary rows (.str.contains("total|england|all"), .unique()) Summary rows are dangerous because they repeat data already counted in the detailed rows, so any sum would be inflated.

    • Provider Org Name had none. The matches were just hospital names containing "all" (Fulwood Hall, Walsall). • Treatment Function Name had a "Total" value. That was the summary row.

  5. Removed them (df_clean = df[df["Treatment Function Name"] != "Total"].copy()) Rows went from 178,171 to 138,494. .copy() makes an independent table so later edits don't trigger pandas warnings or change the original.

  6. Handled the blanks (fillna(0) on the week columns) Since a blank means zero patients, filling with 0 lets sums work correctly. We didn't touch "unknown clock start date", because that column means something different.

  7. Verified the result (nunique(), value_counts()) 23 real specialties remain, and RTT Part Type has 5 values (Part_1A, 1B, 2, 2A, 3). That last check matters for Task 2, because compliance should be calculated on one pathway type, not a mix.

How to say it in your report: "I loaded the NHS RTT May 2026 dataset, confirmed no duplicates, identified a 'Total' summary row in the specialty column and removed it, and treated blank week counts as zero patients.

Task 2¶

Explanation¶

what l did and why

Goal: Measure how many patients are being treated within the NHS 18-week standard, nationally and by trust.

  1. Filtered to Part_2 (df_clean["RTT Part Type"] == "Part_2") The dataset has 5 pathway types. The 18-week standard is about patients still waiting for treatment, which is Part_2. Mixing in completed pathways would measure something different and give a wrong percentage.

  2. Chose the "within 18 weeks" columns (week_cols[:18]) The week columns run from Gt 00 To 01 up to Gt 104. The first 18 cover patients who have waited 18 weeks or less. We printed the first and last name to prove we picked the right ones (Gt 00 To 01 to Gt 17 To 18).

  3. Built a numerator and denominator per row (sum(axis=1))

    • within_18 = patients waiting 18 weeks or less • all_waiting = patients across all week bands

axis=1 adds across the columns of each row.

  1. Tried a sanity check, and learned something We compared all_waiting to the dataset's Total column. It returned nan because Total is blank for all 50,436 Part_2 rows. So the check wasn't possible, but the calculation is still sound because it sums the individual week columns. This is a data quirk to mention in your report.

Overview. This analysis used NHS England Referral to Treatment data for May 2026, covering 7.18 million patients still waiting for treatment (Part_2 pathways). Only 65.5% had waited 18 weeks or less, 26.5 points below the 92% constitutional standard. Key findings 1. Specialty level: Oral Surgery had the lowest compliance (55.4%). Trauma and Orthopaedics had the most patients past 18 weeks (335,969), followed by ENT (244,531) and Gynaecology (224,258). 3.
